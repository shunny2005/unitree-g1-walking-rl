# Challenge Map

This file is a navigation aid, not a replacement for the original challenge document.

The source challenge's intended progression is:
- learn RL/PPO foundations and humanoid-locomotion references;
- understand the team's previous work and end-to-end pipeline;
- build a Unitree G1 walking attempt in simulation;
- prioritize a functioning, understood end-to-end training pipeline over a polished gait;
- define observation/action spaces;
- begin with a minimal reward;
- collect rollouts and use a framework trainer for PPO/value/GAE/clipped updates;
- add domain randomization after basic walking;
- evaluate with deterministic play;
- deliver a short approach/reward writeup, learning curves, and a video/attempt.

The challenge also names Berkeley Humanoid as a code reference and Unitree infrastructure as the build starting point.

Always re-read the original challenge before making a decision that could conflict with these requirements.
